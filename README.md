# 🏦 AI-Powered BFSI Loan Eligibility Checker

**Developer:** Sakshi Chavan  
**Domain:** Banking, Financial Services, and Insurance (BFSI)  
**Tech Stack:** Python, Scikit-Learn, Gradio, Pandas, Google Colab  

## 📌 Project Overview
An automated machine learning web application built for the BFSI sector to evaluate loan applications, predict default risks, and provide real-time eligibility decisions with confidence scoring.

## 🚀 Features
* Instant risk assessment based on credit history and income.
* Interactive mobile-friendly UI built with Gradio.
* Supervised classification using Random Forest.# ai-bfsi-loan-eligibility
