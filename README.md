# 🏦 AI-Powered BFSI Loan Eligibility Checker

**Developer:** Sakshi Chavan  
**Domain:** Banking, Financial Services, and Insurance (BFSI)  
**Tech Stack:** Python 3.10+, Scikit-Learn, Gradio, Pandas, NumPy, Joblib  

---

## 📌 Project Overview
This capstone project implements an automated, end-to-end Machine Learning solution designed for real-time loan underwriting and credit eligibility assessment in the BFSI sector. Using a supervised **Random Forest Classifier**, the system analyzes multi-factor applicant financial profiles (income metrics, credit history, requested loan size) to output an instant decision alongside risk confidence scores.

---

## 🚀 Key Features
- **Instant Risk Assessment:** Evaluates default likelihood in real time using tabular applicant data.
- **Explainable Decision Confidence:** Displays explicit approval percentage and default probability scores.
- **Zero-Footprint Mobile UI:** Powered by Gradio for cross-device compatibility (iOS, Android, Desktop).
- **Automated Feature Engineering:** Combines applicant and co-applicant incomes into total debt capacity parameters.

## 🛠️ Project StructureProblem Statement

Loan eligibility assessment is an important process in the Banking, Financial Services and Insurance (BFSI) sector. This project demonstrates how applicant details can be used to provide an educational loan eligibility indication.

Objectives

- Develop a simple loan eligibility checker.
- Accept income, credit score, loan amount, existing EMI and employment experience.
- Demonstrate the use of technology in financial services.
- Promote responsible use of AI in banking.

Technologies Used

- Python
- NumPy
- Scikit-learn
- Gradio for the Python prototype
- HTML, CSS and JavaScript for the live demo
- GitHub for code management
- Hugging Face Spaces for hosting

Methodology

The Python prototype generates synthetic data and trains a logistic regression model. The live browser demo uses simplified illustrative rules. These are separate implementations.

How to Run the Python Project

1. Download or clone the GitHub repository.
2. Install Python.
3. Open a terminal in the project folder.
4. Run "pip install -r requirements.txt".
5. Run "python app.py".

Live Demo

https://huggingface.co/spaces/sakshichavan2711/ai-bfsi-loan-eligibility

Limitations and Responsible AI

This is an educational project, not a real bank loan approval system. The Python model uses synthetic data, and the live browser demo uses simplified illustrative rules. Neither has been validated for real lending decisions. Real financial applications require appropriate data, testing, privacy protections and fairness checks.

Future Scope

- Test different machine-learning algorithms.
- Improve model evaluation and explainability.
- Add privacy-protecting data handling.
- Evaluate fairness and reliability.

Conclusion

This project demonstrates a basic loan eligibility checking workflow and introduces programming and machine-learning concepts in the BFSI sector. It also highlights the importance of responsible technology in financial services.
